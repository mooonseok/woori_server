---
name: woori-debug
description: 오류나 이상 동작을 재현하고 원인을 좁혀 회귀를 확인한다.
---

1. 실제 입력·환경·호출 경로와 최소 재현을 확보한다. 로그에서 인증값·개인정보를 가린다.
2. 관찰과 가설을 구분하고 가설 하나를 확인하는 검사부터 수행한다.
3. 원인이 확인되면 승인된 수정 범위에서 최소 변경한다. 진단만 요청했다면 결과만 보고한다.
4. 수정 전 실패/수정 후 성공과 인접 부정 경로를 확인한다. 재현하지 못했다면 추정이라고 밝힌다.
대량 로그 분석은 verification-runner에 위임 가능하며 결론·재현 명령·근거·미확인 사항만 받는다.

출처: harness-engineer. 원본 절차를 프로젝트에 맞게 재작성했으며 프레임워크 구조/명명 규칙은 가져오지 않았다.
