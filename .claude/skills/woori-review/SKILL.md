description: 코드 변경의 실제 결함과 보안 또는 회귀 위험을 근거와 함께 검토한다.
---

변경 diff와 실제 호출부를 함께 읽는다. 인증/권한, 입력 검증, 비동기 경합, 데이터 정합성, 성능과 회귀 공백을 확인한다.
각 발견 사항에는 중요도·파일/행·트리거·영향·수정 방향을 붙인다. 확인되지 않은 가설을 결함으로 단정하지 않는다.
폴더 구조·명명 선호를 새로운 컨벤션으로 강제하지 않는다. 요청이 리뷰이면 애플리케이션 코드를 수정하지 않는다.
결과는 핵심 발견과 검증 공백으로 요약하며 전체 소스·로그를 반환하지 않는다.

출처: engineering:code-review. 원본 절차를 프로젝트에 맞게 재작성했으며 프레임워크 구조/명명 규칙은 가져오지 않았다.
