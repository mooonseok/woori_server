실제 요청 DTO와 입력 검증, 세션·멤버십 상태, 오류 응답을 따라 구현한다. 디렉터리 컨벤션은 기존 AGENTS.md를 따른다.
성공 경로와 다른 그룹·탈퇴/제거 회원·취소/만료 초대·중복 사용·관리자 접근 거부를 테스트한다.
초대 한도와 멤버십 생성은 하나의 정합성 경계에서 처리하고 동시 요청·재시도·이미 가입된 경우를 검증한다.
DB 역할은 최소 권한을 유지한다. 트랜잭션 범위와 인덱스, 쿼리 횟수/조회 제한을 실제 호출에서 확인한다.
스키마 변경은 새 migration으로 기록하고 적용 대상과 복구 가능성을 확인한다. 로컬 검증은 기존 격리 runner를 사용한다.

출처: harness-engineer + engineering:testing-strategy. 원본 절차를 프로젝트에 맞게 재작성했으며 프레임워크 구조/명명 규칙은 가져오지 않았다.
